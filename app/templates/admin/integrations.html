Integrações & Webhook

Configure a integração nativa com o UniFi e/ou webhook genérico para outros sistemas.

Integração UniFi (API nativa)

Autoriza clientes diretamente no Guest Portal do UCG Ultra via API Key.

IP ou hostname do roteador UniFi (ex: https://192.168.1.1).

Gere em: UniFi OS → Settings → Admins & Users → [seu usuário] → API Key. Enviada como X-API-KEY em cada requisição.

Normalmente default. Confira em Network → Settings → Site.

Padrão 480 min (8 h). Máx 44640 (31 dias).

Webhook genérico (POST)

Dispara um POST a cada autorização de visitante para n8n, Make ou qualquer endpoint.

O header X-Webhook-Signature: sha256=<hex> é enviado em cada requisição.
